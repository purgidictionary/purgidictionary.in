Writing & literacy

Purgi Script

Because many Purgi-speaking people in Kargil and the wider Purgi-speaking community cannot readily read and write the Purgi script, the first edition of the dictionary uses the Latin alphabet so that Purgi words can be accessed immediately. The Latin alphabet is an accessibility bridge, not a replacement for Purgi script.

6 June 2026

The Purgi script was publicly launched in Kargil on 6 June 2026. For the dictionary project, this creates an immediate opportunity to add the emerging written form of the language to the existing digital lexical resource.

Accessibility first

The current edition uses Latin-script representation for Purgi words as an accessibility bridge. This is not intended to replace Purgi writing.

Next step

Script + transliteration

The proposed Phase II will retain Latin transliteration for accessibility while adding Purgi script, supporting immediate usability and developing written literacy.
