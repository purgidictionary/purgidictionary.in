Writing & literacy

Purgi Script

A new stage for connecting digital language documentation with the written future of Purgi.

6 June 2026

The Purgi script was publicly launched in Kargil on 6 June 2026. For the dictionary project, this creates an immediate opportunity to connect the existing digital lexical resource with the emerging written form of the language.

Accessibility first

The current edition uses Latin-script representation for Purgi words as an accessibility bridge. This is not intended to replace Purgi writing.

Next step

Script + transliteration

The proposed Phase II will retain Latin transliteration for accessibility while adding Purgi script, creating a bridge between immediate usability and developing written literacy.
