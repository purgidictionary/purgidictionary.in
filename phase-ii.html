The underlying principle

The first edition addresses an immediate accessibility need through Latin-script representation. Phase II proposes to add the Purgi script while retaining that accessibility. Together, script and transliteration can support vocabulary documentation, written literacy, language learning and intergenerational transmission.

The goal is not simply a larger dictionary. It is a living digital resource for Purgi.

Phase II is a proposed continuation of the work; features will be developed progressively according to community needs, verification and technical feasibility.
